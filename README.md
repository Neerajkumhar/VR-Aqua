# VR AQUA

A graphite-still-life frontend showcase for custom-labelled packaged drinking water bottles.

## Design direction

Graphite Still Life: a matte graphite field in three close tones, real bottle artwork at full scale on flat product stages, Archivo display against IBM Plex Sans body, one water blue used only for light and state, square corners, hairline rules, and restrained motion. No slogans, lifestyle photography, or decorative apparatus.

## What's included

- 23 bottle designs (12 × 500 ML then 11 × 1 Litre), with Jodhpur 1 Litre as hero-only.
- Semi‑circular bottle carousel with autoplay every 1.8 s and 700 ms slide transition.
- No visible bottom navigation arrows, controls, or pagination dots.
- Footer credit: © 2026 VR AQUA. All rights reserved. | Designed and developed by Visuark ❤️.
- Mobile‑first responsive layout (380 px–1440 px).

## Quick start

```bash
npm install
npm run dev     # start dev server at http://127.0.0.1:4173/
npm run build   # production build
npm run preview # preview production build at http://localhost:4174/
```
